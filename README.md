# Fundamentos de Programación en Java
> Notas personal para publicar en GitHub y repasar en semestres futuros.

## Propósito de este repositorio
Este repositorio concentra ejercicios de **Fundamentos de Programación** en Java, organizados por tema para estudiar más rápido antes de tareas, parciales o examen final.

## Cómo está organizado
Cada carpeta representa una unidad o bloque de práctica:

- `01-condicionales/`  
  Decisiones con `if`, `else`, comparaciones y validaciones.
- `02-ciclos/`  
  Repeticiones con `for`, `while`, `do while` y patrones básicos.
- `03-arreglos-matrices/`  
  Manejo de arreglos y matrices (recorridos, suma de filas/columnas, diagonales).
- `04-metodos-registros/`  
  Separación de lógica en métodos y ejercicios orientados a registro/captura.
- `05-practicas-pa/`  
  Prácticas y ejercicios tipo PA (serie de actividades evaluables).
- `06-examenes/`  
  Ejercicios de evaluación/examen.

## Contenido incluido
- Solo archivos fuente `.java`.
- Sin archivos compilados (`.class`) ni temporales de IDE.
- Total actual: **46 clases Java**.

## Recomendación de estudio (para mí en el futuro)
1. Empezar por `01-condicionales` y `02-ciclos`.
2. Continuar con `03-arreglos-matrices` para lógica intermedia.
3. Repasar `04-metodos-registros` para ordenar mejor soluciones.
4. Cerrar con `05-practicas-pa` y `06-examenes` como simulación de evaluación.

## Cómo usar este repo en GitHub
- Navegar por carpeta temática.
- Abrir cada proyecto y revisar la clase principal en `src/`.
- Comparar soluciones entre ejercicios parecidos.
- Usar este repositorio como historial de progreso académico.

## Nota de mantenimiento
Cuando agregue nuevos ejercicios:
- Mantener el mismo formato de carpetas por categoría.
- Subir solo `.java`.
- Actualizar este README con la nueva cantidad de clases.
